# AffectBridge

> **Bringing the ideas of ALMA-style computational affect into modern LLM-driven game characters.**

AffectBridge is an independent experimental project inspired by **ALMA — A Layered Model of Affect**, originally developed by **Patrick Gebhard and DFKI**.

This project does **not** claim to have invented ALMA or its underlying affective architecture.

AffectBridge exists because we believe the ALMA approach remains highly relevant to modern generative characters, and deserves to be explored in the context of contemporary Large Language Models.

The initial goal is simple:

> **Use the original ALMA runtime as-is, connect it to modern LLM-driven characters, observe how it behaves in practice, and build on the lessons learned.**

The project aims to respect the original work, clearly acknowledge its origin, and explore how its ideas can be extended toward modern game-character systems.
