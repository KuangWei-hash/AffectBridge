## 最終推薦

### Architecture（高信心）

```text
bounded ALMA wire client
  → source-specific Mapper
  → provider-neutral AffectSnapshot
  → trusted target binding + typed SemanticAffectContext
  → replaceable deterministic Formatter
  → authority-bounded Final Renderer
```

理由：這是唯一同時滿足 raw containment、relative semantics、target provenance、offline operation、failure isolation、可測/版本/rollback的共同骨架。即使未來 formatter勝者改變，也不需重寫 ALMA mapper或lexicon。

### v1 presentation（中高信心、待E2確認）

**S4 deterministic layered text 作 provisional default。**

理由：

1. 專案現有 `{{alma_context}}` 是文字 slot，整合變更最小。
2. 明確區分中期 mood與短期 dominant/secondary，符合 ALMA layered model與A07 conflict fixture。
3. 所有 wording由固定 typed lexicon/composition產生，無第二次LLM。
4. canonical sample約70–105 affect tokens，仍bounded且遠低於S7 extra call。
5. 可以把 target/cause unknown寫成固定 constraint，且不需JSON nested keys。

限制：沒有真 Renderer E2，不能宣稱它比S2/S6有較低 hallucination。故 formatter ID必須可設定/rollback。

### Fallback（高信心）

**S2 compact typed phrase。**

它與S4共用semantic core，在budget、format或canary問題時提供更短確定性表示。它不是另一套語意系統，也不作 unavailable fallback；沒有affect資料時應省略slot。

### Alternative experiment（待量測）

**S6 compact typed JSON。**

優勢是欄位/provenance清楚；缺點是canonical sample約90–150 tokens、小2B對keys/nested constraints遵循未知。它應在相同 semantic facts、Renderer prompt與model下跟S2/S4 paired E2，而不是憑「JSON比較結構化」直接上線。

### 非v1

- S1：只作最短enum baseline；裸enum有日常刻板義。
- S3：只作optional dimensional probe；不能取代Fear/Anger/appraisal focus，也不輸出behavior controls。
- S5：default off；模板多樣性收益未證實且增加golden面。
- S7：default off；第二次call、semantic drift、validator/latency/cost/availability。
- S8：future only；需先證明routing rate、長尾value與S7前置條件。

## 必要安全 contract

無論 formatter選擇如何，都必須：

1. active使用 `intensity > baseline`，排序用relative + stable tie-break。
2. Undefined不是不確定；unknown/raw/elicitor不進prompt；Physical/tendency v1排除。
3. mood technical label優先轉安全PAD維度，不推人格/關係。
4. target只有trusted binding可顯示；unknown不能綁current player。
5. emotion/mood只描述狀態；不建立facts、cause、motives、plans、relationships或behavior。
6. malformed/impossible response fail closed；last-good需character/source/version match與age bound。
7. unavailable不是Neutral；formatter失敗不把raw資料轉交Renderer。
8. facts/persona/relationship/situational behavior對內容的authority高於affect。
9. source/domain/lexicon/bucket/policy/formatter/prompt/model可版本化與trace。
10. key/raw private data不進fixture、log、metric label或artifact。
